# Support

## Community beta

Use GitHub Issues for reproducible bugs and GitHub Discussions for integration
questions once the public repository is live. Search existing reports first and
include the output of:

```bash
npx @gradia/guard doctor --json
npx @gradia/guard capabilities --json
```

Remove customer content, secrets, raw provider responses, and personal data
before sharing any receipt. Community support is best-effort and carries no
uptime, response-time, retention, or compatibility SLO.

## Managed Gradia

Authenticated ingestion, remote anchors, governed human/model review,
Analytics+, regression evidence, certificates, and Gradia Universe composition
are deployment-specific managed capabilities. Access and contractual support
are provided only under the applicable Gradia agreement. Paying for service can
change availability and support; it cannot change what an artifact observed,
make a failed integrity check pass, or upgrade an ineligible claim.
